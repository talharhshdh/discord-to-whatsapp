The latest stable version of Google Chrome across Windows, macOS, Linux, and Android is 149.0.7827 (currently rolling out as an Early Stable release), while the iOS version is 149.0.7827.26. 
Chrome updates itself automatically, but you can manually check for and apply the latest version by following these steps: 
  1. Open Google Chrome.
  2. Click the three dots menu icon in the top-right corner.
  3. Hover over Help and click on About Google Chrome.
  4. Chrome will automatically check for the update and download it.
